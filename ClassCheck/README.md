# IESTPAN-ClassCheck

Sistema ClassCheck para la gestión de asistencia y actividades académicas.

## Estructura del proyecto

```text
ClassCheck/
├── src/                    # Código fuente PHP (mantenido por el equipo)
├── docs/                   # Documentación del proyecto
│   └── cronograma-gantt.xlsx
├── assets/
│   ├── diseños/             # Diseños y recursos visuales
│   └── pantallas/           # Capturas de las interfaces del sistema
├── README.md
└── .gitignore
```

## Organización

- `src/`: contiene la aplicación y sus módulos. No reemplazar esta carpeta al incorporar esta estructura.
- `docs/`: almacena documentos del proyecto, incluido el cronograma Gantt cuando esté listo.
- `assets/diseños/`: almacena los diseños aprobados del sistema.
- `assets/pantallas/`: almacena capturas de las pantallas implementadas.

## Requisitos

- PHP (versión compatible con el proyecto).
- Servidor web local, por ejemplo Apache.
- Motor de base de datos configurado por el equipo.

## Instalación

1. Clonar o descargar el repositorio.
2. Configurar el servidor local para servir la carpeta del proyecto.
3. Configurar la conexión a la base de datos según las instrucciones del equipo.
4. Abrir el punto de entrada definido dentro de `src/`.

> Nota: completar este apartado con los datos reales de instalación y configuración del proyecto. No publicar contraseñas ni credenciales.
